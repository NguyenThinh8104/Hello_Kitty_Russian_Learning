# Aymi Russian assets and study data

Dictionary accents and English glosses were derived from the OpenRussian CSV
dataset at https://github.com/Badestrand/russian-dictionary, retrieved 2026-11-24.
They were selected, shortened, corrected for textbook context, and supplemented
with English and Vietnamese explanations. The derived vocabulary-data.js dataset
is distributed under CC BY-SA 4.0; see openrussian-cc-by-sa-4.0.txt. This does not
relicense unrelated application code. The chapter word lists were transcribed
from the personal copy of I Love Russian A1, second edition (2017), supplied by
the user. The PDF itself is not included in public source or cloud IPA builds.

https://github.com/googlefonts/noto-emoji/tree/main/2D/svg

Noto Sans font: Noto project authors, SIL Open Font License 1.1,
see noto-sans-ofl.txt. https://github.com/google/fonts/tree/main/ofl/notosans

The application logo is the unchanged image supplied by the user. Platform
icons are technical size exports of that image. Hello Kitty is © SANRIO;
this personal study companion is not affiliated with SANRIO or Liden & Denz.
The optional unused upscaled logo variant was made with ImageGen from the
user's reference; the app uses the original artwork.

The eight speaking prompts come from the user's A1 speaking-topics DOCX.
Model monologues, reading passages, questions, and grammar explanations are
supplementary learning content. The app does not reproduce all book exercises.

Background wallpaper: unchanged Hello Kitty image supplied by the user on 2026-11-24. The app displays it using responsive CSS, with translucent reading surfaces.
